Topic 1 — What is a Matrix?

A matrix is a rectangular arrangement of numbers, symbols or expressions in rows and columns.

Worked Example

If A = [[1,2],[3,4]], then A has 2 rows and 2 columns. Therefore its order is 2 × 2.

📝 Quick Notes

  • Order = rows × columns.
  • Horizontal arrangement = row.
  • Vertical arrangement = column.
  • Always check dimensions before operations.
